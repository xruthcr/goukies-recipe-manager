# Goukies Recipe Manager

Aplicación web para la gestión de recetas desarrollada con React, Vite y TypeScript.

---

# Tecnologías

- React
- Vite
- TypeScript
- React Router DOM
- PNPM
- ESLint

---

# Instalación

## Clonar repositorio

```bash
git clone https://github.com/xruthcr/goukies-recipe-manager.git
```
## Instalar dependencias
Dentro del proyecto Vite+React, instalar las dependencias
```bash
pnpm install
```
